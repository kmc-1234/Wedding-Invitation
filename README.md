## Photos and music

The invitation and sharing preview use an optimized `couple-portrait.jpg` and `wedding-preview.jpg`, derived from `couple.png`. The portrait has a subtle filter applied through `style.css`.

The music file is `visa_vintara_saradaga.mp3`. To change it, replace the file or edit the audio element’s `src` in `index.html`. The built-in instrumental synthesizer provides a fallback.

## Preview locally

```bash
python3 -m http.server 8000
```

Open http://localhost:8000.

The invitation includes an opening seal, music controls, flower effects, directions to the supplied village, timed calendar downloads, and a blessings wall stored locally in each guest’s browser.
